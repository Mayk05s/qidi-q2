# Панель на принтере

Страница на порту 18770 и кнопки в меню Fluidd. Ставится, когда включён пакет, которому она нужна.

## Что ставит

- Файлы панели в `/home/qidi/qidi_panel`. Твои материалы и цвета там же, при удалении остаются.
- Службу `qidi-panel`.
- Одну строку в `fluidd/index.html` и файл `fluidd/qidi_panel_link.js`.

Вкладки показываются только для включённых пакетов.

## Вкладки

- «Слоты принтера»: катушки 1A–1D, замена материала карандашом, кнопка «Перечитать», остаток на катушке, если стоит «Расход пластика». «Перечитать» качает катушку мотором Box: 100 мм назад, 50 мм вперёд и обратно на место, поэтому просит подтверждение. Заправленный слот читать нельзя.
- «Напечатать образцы»: количество для каждой катушки, надпись, превью, открытие проекта в QIDI Studio или 3MF.
- «Материалы»: типы пластика и материалы, с которыми ты работаешь. Только они показываются при выборе замены и записи меток, список на принтере не меняется.
- «NFC-метки» и «Справка» появляются со своими пакетами.

Свои цвета добавляются плиткой «+» в редакторе. Палитра и материалы хранятся в `/home/qidi/qidi_panel` и при удалении остаются.

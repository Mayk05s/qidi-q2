# Быстрая печать

Перед печатью принтер замеряет не весь стол, а зону модели.

## Как это работает

- Штатный макрос QIDI всегда меряет всю глубину стола и по X не меньше 60–210 мм. Наш макрос `BED_MESH_CALIBRATE` в `qidi_patcher.cfg` перекрывает его, файлы QIDI не меняются.
- Замеряется зона модели с запасом 10 мм и линия очистки спереди: она идёт с опусканием до Z-0.1, вне замера сопло могло бы задеть стол. Для модели 40 мм по центру это 20 точек вместо 36.
- Нужна нарезка с подписью объектов, в профиле Q2 она включена. Без неё замеряется весь стол.
- Замерять строго модель: `variable_keep_purge: 0` в `qidi_patcher.cfg`. Первую такую печать смотри.

## Не проверено

На настоящей печати.

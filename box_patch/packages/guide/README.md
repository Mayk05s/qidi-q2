# Справка по пластику

Сушка, температуры, хранение и силикагель для Box: кнопка «Справка» в меню Fluidd и вкладка в панели.

Ставит `qidi_panel/drying_guide.html`. В Klipper ничего не меняет.

Черновик: пределы температур для печатных катушек это оценка, а не данные QIDI.

## Что лежит в папке пакета

| Где | Что это |
|---|---|
| `README.md`, `package.json` | Справка и описание пакета, их читает патчер |
| `printer/drying_guide.html` | Страница справки, ставится в `qidi_panel/drying_guide.html` |

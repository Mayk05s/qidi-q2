# Состояние проекта и что дальше

Записано 2 ноября 2026. Как пользоваться панелью, описано в `README.md`.

## Работа сейчас

- Принтер QIDI Q2 с QIDI Box, адрес и пароль в `.env` (в git не попадает).
- `./setup.sh`: пункт 1 ставит модуль и панель на принтер, пункт 4 запускает панель на Mac. Пароль вводит сам пользователь, агент не вводит.

## Проверено на железе

- Чтение меток Bambu и QIDI через считыватели Box, сохранение в слот.
- Панель внутри Fluidd и цвета в её панели материалов.
- Запись через ACR122U с подтверждением чтением (метка E83E2288).

- Учёт остатка на катушках: `SpoolUsage` в модуле, активный слот берётся из `box_extras.loaded_slot`, расход из `print_stats.filament_used`. На печати не проверен. Чтение общего номера катушки Bambu из блока 9 тоже: на случай неудачи есть запасной ключ по UID.

## Что важно помнить

- Не менять список материалов принтера.
- Метку Bambu перезаписать нельзя. Запись идёт только на метку с прочитанным UID и только в блоки 4 и 5, блок 7 запрещён.
- Считыватель Box нельзя использовать во время печати: команды идут в общей очереди Klipper. ACR122U на Mac можно.
- Новый код модуля применяется только после `systemctl restart klipper`, команда `RESTART` оставляет старый.
- Копии меток в `backups/` панель больше не делает, старые файлы можно удалить.
- Интерфейс на русском, скругления, подтверждения через диалог, перед установкой показывать интерфейс на демо.
- Тесты: `python3 -B -m unittest` отдельно в `box_patch` и `tag_writer`.
- Демо для проверки интерфейса с имитацией принтера нужно написать заново: прежнее лежало во временной папке. Основа есть в `FakeBoxPrinter` в `tag_writer/test_qidi_tag_tool.py`.
